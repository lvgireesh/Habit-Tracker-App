📈 Habit Tracker App

An interactive web application built with HTML5, CSS3, and vanilla JavaScript. The app allows users to create daily habits, track progress with dynamic visual indicators, and persist data using browser `LocalStorage`.

---

✨ Features

**Habit Management:** Add new daily habits and delete old ones.
**Streak Tracking:** Keep track of daily completion streaks to stay motivated.
**Dynamic Progress Bars:** Real-time visual progress updates as habits are checked off.
**Data Persistence:** Built-in `LocalStorage` support guarantees user data remains intact after refreshing or closing the browser.
**Fully Responsive UI:** Optimized layout for desktop, tablet, and mobile browsers.

---

🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript (ES6+)
**Storage:** Web Storage API (`LocalStorage`)
